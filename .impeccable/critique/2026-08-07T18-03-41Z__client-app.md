## Design Specificity Verdict

**LLM assessment:** Category-interchangeable with pockets of authorship. The visual system reads as a polished 2024–2026 developer portfolio template (Geist Sans, Apple-adjacent tokens, circular portrait hero, GitHub calendar widget). Photography section is the strongest authored moment. Recruiter-first intent in config.ts is not fully expressed in the UI — LinkedIn contact is footer-only, hero leads with portrait not proof artifacts.

**Deterministic scan:** 0 findings from detect.mjs across client/app and client/components. Clean on slop patterns; manual review still surfaced IA, a11y, and theming issues the detector does not cover.

**Browser visualization:** Not available this session (no browser automation). Dev server confirmed running at localhost:3000.

## Overall Impression

Competent, clean portfolio with strong photography execution and a solid accessibility baseline. The single biggest opportunity: align the Experience-mode goal (artifacts lead, interface recedes) with recruiter-first intent — surface proof and contact paths above the fold, reduce GitHub-calendar chrome, and fix "Work"/"Portfolio" IA confusion.

## What's Working

1. **Recruiter-first IA skeleton** — About → Work → Portfolio nav order and hero "View resume" CTA correctly prioritize hiring path.
2. **Photography execution** — Masonry gallery, lightbox, scrubber pagination embody Experience mode best.
3. **Accessibility baseline** — 44px touch targets on nav, focus-visible:outline-accent sitewide, prefers-reduced-motion on reveals and smooth scroll.

## Priority Issues

### [P0] No recruiter contact path above the fold
- **Why:** CONTACT.linkedin exists in config.ts but UI only exposes LinkedIn as a footer icon. Recruiters lose conversion at highest-intent moment.
- **Fix:** Add "Connect on LinkedIn" to hero CTAs and sticky Resume sidebar.
- **Suggested command:** `/impeccable clarify About`

### [P1] GitHub calendar violates Experience mode
- **Why:** Full-width green heatmap above curated projects reads as dashboard widget, breaks accent color story, adds extraneous load.
- **Fix:** Remove or collapse to one-line stat; move below top projects if kept.
- **Suggested command:** `/impeccable distill Projects`

### [P1] "Work" nav hides two major sections
- **Why:** #work contains Resume and Projects with no sub-nav; recruiters clicking Work may never discover Projects.
- **Fix:** Split nav, add sticky sub-nav pills, or rename with anchor links.
- **Suggested command:** `/impeccable layout HomeClient work section`

### [P1] Project image link has no accessible name
- **Why:** ProjectRow.tsx alt="" on linked thumbnail leaves screen readers with unnamed link.
- **Fix:** Use alt={title} on project images.
- **Suggested command:** `/impeccable harden ProjectRow`

### [P1] Lightbox lacks focus trap
- **Why:** Tab can escape modal to background content in Gallery.tsx.
- **Fix:** Trap focus, inert background, restore focus on close.
- **Suggested command:** `/impeccable harden Gallery`

### [P2] Design token fragmentation across routes
- **Why:** Project detail, 404, admin use slate-* instead of ink/accent tokens.
- **Fix:** Extend token system; align CTA shapes with main site.
- **Suggested command:** `/impeccable extract projects/[slug]`

### [P2] Hero leads with identity chrome, not proof artifacts
- **Why:** Portrait-first hero is interchangeable; Springer publication and NLP pipeline are text-only below fold.
- **Fix:** Add proof strip with publication badge, impact stat, top project thumbnail.
- **Suggested command:** `/impeccable layout About`
